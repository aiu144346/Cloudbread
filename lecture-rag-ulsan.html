STEP 1

국가법령정보센터 자치법규 공공데이터 수집 파이프라인

Data Pipeline

대한민국 자치법규는 국가법령정보센터(law.go.kr) DRF Open API를 통해 전산화되어 있습니다. 광역자치단체(울산광역시)는 지자체 기관명 울산광역시, 법규 종류 조례로 필터링하여 총 700여 건 중 시민 체감도가 가장 높은 5대 핵심 조례를 선별하여 수집합니다.

Python을 활용한 공공법령 API 수집 코드 data_collection.py 
import urllib.request
import xml.etree.ElementTree as ET

# 울산광역시 청년 기본 조례 (MST: 2110545)
url = "https://www.law.go.kr/DRF/lawService.do?OC=test&target=ordin&MST=2110545&type=XML"
req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
with urllib.request.urlopen(req) as resp:
    root = ET.fromstring(resp.read())
    law_name = root.find('.//자치법규기본정보/자치법규명').text
    print(f"조례명: {law_name}")
🏛️ 광역자치단체(시청) vs 기초(구청) 차이

광역 조례는 울산시 전체 5개 구·군을 관할하며 대규모 재정 지원(경영안정자금 융자, 특별교통수단 도입 등)의 총괄 기준을 수립합니다.

⚡ 5대 핵심 타깃 조례 선정

청년 기본 조례, 인구감소 및 저출생 대응 조례, 소상공인 지원 조례, 침수방지시설 설치 지원 조례, 교통약자 이동편의 증진 조례를 선정합니다.

STEP 2

자치법규 구조화 및 조항(Article) 단위 Chunking

Article Chunking

일반 문서는 문단이나 글자 수(500~1000자)로 단순 분할하지만, 법령 데이터는 반드시 조(Article) 단위로 청킹해야 법적 맥락이 훼손되지 않습니다. 또한 각 조에 딸린 항(Paragraph)과 호(Sub-paragraph)를 조문 본문과 하나의 묶음으로 결합합니다.

RAG 코퍼스 JSONL 표준 스키마 구조
{
  "id": "ULSAN_CITY_2110545_000200",
  "law_name": "울산광역시 청년 기본 조례",
  "org": "울산광역시",
  "category": "청년/일자리",
  "article_no_display": "제2조(정의)",
  "article_title": "정의",
  "content": "제2조(정의) 이 조례에서 사용하는 용어의 뜻은 다음과 같다.\n1. \"청년\"이란 19세 이상 39세 이하인 사람을 말한다. 다만...",
  "link": "https://www.law.go.kr/DRF/lawService.do?OC=test&target=ordin&MST=2110545&type=HTML"
}
STEP 3

의도(Intent) 분석 기반 광역 시맨틱 부스팅 RAG 검색 엔진

Intent Boosting

일반적인 RAG에서 "울산시 청년 나이는?"이라고 검색하면 '청년' 단어가 수십 번 등장하는 센터 설치 조항이나 위원회 운영 조항이 검색 점수가 높아 엉뚱한 답을 낼 위험이 있습니다. 이를 해결하기 위해 질문자의 의도(나이, 금액, 지원 자격)를 감지하여 정의 조항(제2조)에 가중치(+150점)를 부여하는 인텐트 부스팅(Intent Boosting) 알고리즘을 적용합니다.

인텐트 부스팅 검색 로직 (JavaScript / Python 공통)
// 질문 의도 감지
const isAge = /나이|연령|몇\s*세|청년\s*기준/.test(query);
const isYouth = /청년/.test(query);

// 청년 나이 질문 시 제2조(정의)에 강력한 가중치 부여
if (isYouth && isAge && item.law_name.includes('청년 기본 조례')) {
  if (item.article_title.includes('정의') || item.article_no_raw === '000200') {
    score += 150; // 1순위 강제 부스팅
  }
}
STEP 4

프롬프트 엔지니어링 & 다이렉트 앤서(Direct Answer) 합성

Synthesis

시민 사용자는 길고 복잡한 법조문 전문을 읽기보다, "내가 원하는 답이 무엇인가?"를 즉시 확인하길 원합니다. 따라서 검색된 조항의 본문에서 핵심 수치와 대상(19세 이상 39세 이하 등)을 최상단에 다이렉트 앤서로 요약하고, 그 하단에 근거 조항과 원문 링크를 정갈하게 배치합니다.

울산광역시 조례 RAG 마스터 프롬프트 (수강생 복사용) 
당신은 대한민국 광역자치단체 행정 조례 전문 AI 비서이자 '울산광역시 자치법규 RAG 챗봇'입니다.
현재 작업 폴더(Workspace) 내의 `ulsan_city_ordinances_rag_corpus.jsonl` 파일(또는 조례 데이터셋)을 바탕으로 시민들의 행정/복지/생활 질문에 대해 울산광역시 조례 원문을 철저히 검증하여 정확하게 답변해야 합니다.

### [필수 지침 및 답변 원칙]
1. 광역 조례 원문 최우선:
   - 추측이나 환각(Hallucination)을 철저히 배제하고, 반드시 코퍼스에 등록된 울산광역시 조례 조항만을 근거로 답변하세요.
   - 기초자치단체(구·군) 조례와 혼동하지 마시고, 울산광역시 광역 시정 차원의 지원 기준을 명확히 안내하세요.
   - 정보가 코퍼스에 없는 경우 솔직하게 "해당 내용은 울산시 핵심 조례 데이터에서 확인되지 않으므로 울산광역시청 해당 주관부서 문의가 필요합니다"라고 안내하세요.

2. 의도 기반 조항 우선순위(Intent Boosting):
   - 질문자가 "나이", "연령", "청년 기준"을 물을 때는 반드시 「울산광역시 청년 기본 조례」 `제2조(정의)`의 연령 기준("19세 이상 39세 이하인 사람")을 1순위로 추출하여 최상단에 제시하세요.
   - "소상공인 지원" 또는 "경영안정자금"을 물을 때는 「울산광역시 소상공인 지원 조례」 제4조~제5조의 경영안정자금 융자지원, 특례보증 지원을 우선 제시하세요.
   - "침수방지시설" 또는 "차수판"을 물을 때는 「울산광역시 침수방지시설 설치 지원 조례」의 단독·공동주택 및 소규모 상가 차수판 설치비용 지원 조항을 최우선 추출하세요.
   - "교통약자" 또는 "부름콜"을 물을 때는 「울산광역시 교통약자의 이동편의 증진 조례」의 특별교통수단 및 이동지원센터 규정을 안내하세요.
   - 조항 번호는 `000200` 형식이 아닌 사람이 읽기 편한 `제2조`, `제3조` 형식으로 자동 변환해 표기하세요.

3. 답변 출력 표준 템플릿:
   답변 시 반드시 다음 3단계 구조로 정갈하게 가독성을 높여 출력하세요.
   
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   🎯 [핵심 요약]
   - 질문에 대한 핵심 결론 및 수치(연령, 금액, 대상 요건 등)를 1~2문장으로 명확히 요약
   
   📜 [근거 광역 조례 및 세부 조항]
   - 조례명: 울산광역시 OOO 조례
   - 관련 조항: 제O조(제목)
   - 소관 부서: OOO과
   - 조항 본문 발췌: "..."
   
   💡 [시민 안내 및 팁]
   - 신청 자격, 구비 서류, 신청 기관(울산광역시청 주관부서 또는 관련 산하기관) 등 시민 관점의 실질적 팁 제공
