STEP 2

생애주기 × 거주 지역(5개 구·군) 다중 의도 부스팅(Intent Boosting)

Lifecycle & Geo Routing

시민이 "남구 임산부 혜택 알려줘" 또는 "어르신 대상포진 무료 접종 나이"라고 질문할 때, 검색 엔진이 ① 생애주기 의도(임산부, 영유아, 청장년, 어르신), ② 세부 토픽(보건증, 금연, 치매, 예방접종, 산후조리), ③ 지역명(중구·남구·동구·북구·울주군)을 동시에 분석하여 실용 가이드를 최상단(Top-1)에 배치하고, 관련 조례 원문을 후속 근거(Top-2~4)로 자동 매칭합니다.

다중 인텐트 부스팅 스코어링 알고리즘
// 1. 실전 가이드 우선 부스팅 + 법적 근거 조례 동반 노출
if (item.id.startsWith('ULSAN_HEALTH_GUIDE_')) {
  score += 35; // 시민 친화적 요약/준비물/전화번호 카드 우선순위 부여
}

// 2. 토픽별 정밀 부스팅 (예: 보건증/건강진단결과서, 치매안심센터, 대상포진 등)
if (/보건증|건강진단결과서|수수료/.test(query)) {
  if (item.id === 'ULSAN_HEALTH_GUIDE_ADULT_CERT_01') score += 220;
  if (item.law_name.includes('지역보건의료시설 수가')) score += 90;
}

// 3. 구·군 지역 매칭 부스팅 (중구, 남구, 동구, 북구, 울주군)
for (const dist of ['중구', '남구', '동구', '북구', '울주군']) {
  if (query.includes(dist) && item.org.includes(dist)) score += 95;
}

수강생 핵심 교육 포인트

수강생들에게 강의하실 때 "키워드/규칙 기반 클라이언트 RAG"와 "LLM 결합형 하이브리드 RAG"의 차이를 설명하시는 좋은 교육 사례로 활용하실 수 있습니다:

1단계 (현재 웹앱 방식 - 무과금·초고속) Client-Side Engine

형태소(조사) 제거 + 유의어 사전(Synonym Dictionary) + 도메인 실무 요약본(FAQ 청크) 보강으로 API 비용 0원으로 95% 이상의 시민 질문을 초고속으로 커버합니다. 별도 서버 운영비 없이 웹 브라우저에서 즉시 동작하는 것이 최대 강점입니다.

2단계 (안티그래비티 / Gemini API 결합 방식) LLM Hybrid

코퍼스에 직접적인 단어가 없더라도 거대언어모델(LLM)이 문맥을 추론하여 답변하도록 Google Antigravity에서 ulsan_health_centers_rag_corpus.jsonl을 열고 아래 마스터 프롬프트를 적용하면, 어떤 구어체나 복합 질문에도 100% 자연스러운 상담이 가능합니다.
