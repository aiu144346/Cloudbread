STEP 1

공공데이터 API로 지자체 조례 전수 수집

Tool: Python, law.go.kr DRF API

일반 웹 크롤링 대신 국가법령정보센터에서 제공하는 공식 DRF(대국민 법령정보 오픈API)를 활용하여, 울산광역시 중구청의 조례 432건 전체 목록과 조문 전문 XML을 누락 없이 안전하게 수집합니다.

핵심 포인트:

• 지자체명 검색 시 기본 20건씩 페이징되므로 루프를 통해 524건(조례 432건, 규칙 92건)을 전수 수집합니다.

• 각 조례의 고유 식별자인 MST(자치법규일련번호)를 추출하여 상세 본문 호출 키로 사용합니다.

import urllib.request, urllib.parse, xml.etree.ElementTree as ET

# 1. 울산광역시 중구 자치법규 목록 검색
query = urllib.parse.quote('울산광역시 중구')
url = f'https://www.law.go.kr/DRF/lawSearch.do?OC=test&target=ordin&type=XML&query={query}&page=1'

req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
with urllib.request.urlopen(req) as resp:
    tree = ET.fromstring(resp.read())

for item in tree.findall('.//law'):
    name = item.findtext('자치법규명')
    mst = item.findtext('자치법규일련번호')
    law_type = item.findtext('자치법규종류')
    if law_type == '조례':
        print(f"조례명: {name} | MST: {mst}")
STEP 2

법률 문서에 최적화된 조문 단위(Article) Chunking

Format: JSON Lines (.jsonl)

일반 문서는 500자 단위나 단락 단위로 자르지만, 법률 문서는 절대 글자 수로 자르면 안 됩니다. 반드시 `제1조(목적)`, `제2조(정의)`, `제3조(지원대상)`과 같이 의미가 완결되는 조문 단위로 분할해야 맥락 단절(Context Loss)을 막을 수 있습니다.

조문 청크에 반드시 바인딩해야 할 5대 메타데이터:

1. ordinance_name: 소관 조례명 (예: 울산광역시 중구 청년 기본 조례)

2. article_no: 조문 번호 정규화 (000200 ➔ 제2조)

3. article_title: 조문 제목 (예: 정의, 지원대상, 설치·운영)

4. prom_no: 공포번호 (법적 효력 검증용)

5. rag_chunk: 검색용 합성 텍스트 "[조례명 - 제O조 제목]\n조문 본문"

STEP 3

의도(Intent) 분석 기반 시맨틱 부스팅 RAG 검색

Algorithm: Stopword Filtering + Intent Boosting
⚠️ 수강생이 실무에서 100% 겪는 RAG 함정:
"청년 나이 기준은?"이라고 물었을 때, 단순 단어 빈도(TF)만 계산하면 '청년'과 '기준'이라는 단어가 수십 번 들어간 제21조(청년센터 설치운영)가 1위로 잡히고, 정작 정답인 제2조(정의: 19세~39세)는 밀려납니다.

해결책: 불용어('울산', '중구', '조례상', '기준은', '몇세' 등)를 제거하고, 질문의 의도를 분석하여 연관 조항에 가중치(+100~120점)를 직접 부여합니다. 

// Intent-Aware 가중치 부여 알고리즘
const isAge = /나이|연령|몇\s*세|청년\s*나이|정의/.test(query);

for (const item of corpus) {
  let score = calculateTokenScore(query, item);

  // 청년 나이를 묻는 의도일 경우 제2조(정의)를 최우선 1위로 부스팅!
  if (isAge && item.ordinance_name.includes('청년 기본 조례')) {
    if (item.article_title.includes('정의') || item.article_no === '2') {
      score += 120; // 압도적 가중치 부여
    }
  }
}
STEP 4

프롬프트 엔지니어링 & 다이렉트 앤서(Direct Answer) 합성

Prompt Engineering & Synthesis

RAG의 완성은 단순히 검색된 조항을 보여주는 것이 아니라, 구민의 질문에 1:1로 직접 대답하는 문장을 합성(Synthesis)하는 것입니다.
