매주 엑셀 데이터를 복사해 PPT 차트를 만드느라 야근하는 직장인, 우리 동네 공공데이터나 매장 실적을 직관적인 웹페이지로 시각화하고 싶은 일반 시민과 소상공인을 위한 특화 커리큘럼입니다. HTML, CSS, 자바스크립트를 몰라도 구글 안티그래비티(Google Antigravity) 에이전트에게 요구사항을 말하면, KPI 카드, 동적 차트, 다크모드, 필터링이 결합된 반응형 웹 대시보드를 30분 만에 구현하고 인터넷에 무료로 배포할 수 있습니다.

Before vs After

왜 기존 방식 대신 구글 안티그래비티 대시보드인가?

기존의 데이터 보고 및 시각화 고충
  • • 수작업 야근: 매번 엑셀 데이터를 피벗 테이블 돌리고 파워포인트에 캡처해서 붙여넣는 반복 작업.
  • • 비싼 BI 툴 비용: 태블로(Tableau), 파워BI 등은 월 수십만 원의 라이선스 비용과 높은 학습 장벽 존재.
  • • 개발자 의존성: 웹 대시보드 하나 만들려면 프론트엔드/백엔드 개발자에게 일정 요청하고 수주 대기.
  • • 정적인 보고서: PDF나 출력물은 필터를 누르거나 드릴다운할 수 없어 실시간 소통 불가.
구글 안티그래비티 활용 시의 혁신
  • • 자연어 원클릭: "이 엑셀로 월별 추이와 목표 달성률 대시보드 만들어줘" 한 문장으로 코드 완성.
  • • 구독료 0원: 오픈소스 차트 라이브러리(Chart.js)와 무료 웹 호스팅(GitHub/Vercel)으로 영구 무료.
  • • 비전공자 자립: 개발자 도움 없이도 직장인·시민이 혼자서 기획부터 디자인, 배포까지 100% 완수.
  • • 인터랙티브 웹: 클릭 한 번에 기간별 필터링, 모바일 스마트폰 최적화, 실시간 URL 팀 공유 가능.
Step-by-Step Curriculum

4단계 실전 커리큘럼 로드맵

이론 10% + 실습 90%로 구성되어 강의 종료 시점에 모든 수강생이 본인만의 라이브 대시보드를 손에 쥡니다.

MODULE 01

오리엔테이션 & 구글 안티그래비티 온보딩 (30분)

30 min

에이전틱 AI 코딩 비서 Google Antigravity의 개념과 작동 원리를 이해하고, 개발 환경 설치 없이 즉시 브라우저와 워크스페이스를 연동하는 방법을 배웁니다.

1. AI 에이전트 개념

단순 질의응답 챗봇 vs 스스로 파일을 생성하고 실행하는 에이전트의 차이점 파악

2. 워크스페이스 세팅

안티그래비티 대화창, 파일 탐색기, 실시간 브라우저 프리뷰 창의 3단 구조 익히기

3. 첫 인사이트 테스트

"간단한 환영 카드 웹페이지 만들어줘" 테스트 명령을 통해 5초 만에 결과 확인

MODULE 02

데이터 준비 & AI 프롬프트 엔지니어링 (40분)

40 min

실무에서 쓰이는 지저분한 엑셀(XLSX)이나 CSV 파일, 공공데이터 포털(data.go.kr)의 데이터를 안티그래비티에 입력하고, AI가 분석하기 가장 좋은 형태로 정제 및 구조화하는 기법을 배웁니다.

1. 데이터 전처리 요령

병합된 셀 해제, 날짜/금액 포맷 통일, 빈칸 처리 등 AI 친화적 테이블 구성법

2. 핵심 KPI 지표 정의

우리 조직/가게/동네에서 가장 중요한 4대 지표(총매출, 달성률, 고객수 등) 선별

3. 차트 유형 매핑

추이는 Line 차트, 비중은 Donut 차트, 비교는 Bar 차트로 알맞게 지시하는 원칙

MODULE 03

인터랙티브 웹 대시보드 실전 제작 (80분)

80 min

구글 안티그래비티에게 마스터 프롬프트를 전송하여 실제 반응형 대시보드 소스코드를 생성하고, 에이전트와 대화하며 실시간으로 디자인과 기능을 커스터마이징합니다.

실습 트랙 A (직장인 맞춤)

실시간 매출 및 업무 KPI 모니터링: 부서별 실적 달성 현황, 월별 매출 곡선, 팀별 기여도 도넛 차트 및 필터링 기능 구현.

실습 트랙 B (전문직/병원 CRM)

피부과 원장님 고객증대 & CRM: 마케팅 유입 퍼널, 보톡스/리프팅 재시술 골든타임 알리미, 비식별 EMR 엑셀 브릿지 연동.

피부과 전용 데모 열기 →
실습 트랙 C (시민·소상공인 맞춤)

우리 동네 생활공공데이터 & 매장: 보건/복지 혜택 신청 통계, 상권 유동인구 지표, 일별/요일별 고객 주문 현황 시각화.

MODULE 04

무료 웹 호스팅 배포 & 팀 공유 (30분)

30 min

내 컴퓨터에서만 보이는 로컬 파일이 아닌, 인터넷 주소(URL)를 가진 실제 웹사이트로 1분 만에 무료 배포하고 스마트폰으로 확인하는 노하우를 습득합니다.

1. GitHub Pages / Vercel 배포

별도 서버 계약 없이 클릭 몇 번으로 평생 무료 HTTPS 웹 주소 생성

2. 모바일 반응형 검증

스마트폰 카카오톡/슬랙으로 팀원들에게 링크를 공유하고 모바일 뷰 확인

3. 데이터 업데이트 자동화

새로운 엑셀 데이터가 추가되었을 때 대시보드를 10초 만에 갱신하는 꿀팁

Antigravity Prompt Template
당신은 최고 수준의 '풀스택 웹 프론트엔드 & 데이터 시각화 전문 시니어 엔지니어'입니다. 현재 워크스페이스에 첨부된 데이터(엑셀/CSV/JSON)를 바탕으로, 비전공자 및 경영진, 시민들이 한눈에 보고 인사이트를 얻을 수 있는 프리미엄 반응형 웹 대시보드 'index.html'을 단일 파일로 작성해 주세요. [요구 디자인 & UI 스펙] 1. 디자인 스타일: 현대적인 다크 테마(Dark Mode), 슬레이트/인디고 글래스모피즘(Glassmorphism) 카드 스타일 적용. 2. 폰트 & 아이콘: CDN 기반 'Pretendard' 폰트 및 'Font Awesome 6' 아이콘 라이브러리 탑재. 3. CSS 프레임워크: 별도 빌드 없이 바로 구동되는 'Tailwind CSS CDN' 사용. 4. 차트 라이브러리: 인터랙티브한 애니메이션을 지원하는 'Chart.js CDN' 활용. [대시보드 필수 구성 요소] 1. 상단 글로벌 헤더: 대시보드 타이틀, 실시간 상태 배지(LIVE), 마지막 업데이트 일시, 기간 선택 필터 드롭다운. 2. 4대 핵심 KPI 카드: - 총 실적 / 누적 규모 (전기 대비 증가율 % 표시) - 목표 달성률 (초과 달성 배지 표시) - 만족도 또는 핵심 품질 지표 - 절감 시간 또는 처리 효율성 지표 3. 인터랙티브 차트 그리드: - 메인 시계열 추이선(Line Chart): 최근 6개월 추이 및 목표치 점선 비교. - 구성비 도넛 차트(Doughnut Chart): 카테고리/부서/분야별 점유율. - 비교 막대 차트(Bar Chart): 부문별 목표 달성률 비교. 4. 상세 데이터 테이블: - 주요 프로젝트/민원 리스트 표 (상태별 배지, 수치, 정렬 지원). - '엑셀/CSV 다운로드' 버튼 클릭 시 브라우저에서 즉시 다운로드되는 자바스크립트 함수 내장. 5. 모바일 반응형: 스마트폰, 태블릿, PC 와이드 모니터에서 완벽하게 그리드가 재배치되도록 구현. 지금 즉시 실행 가능한 완성형 단일 HTML 파일로 작성해 주세요!
